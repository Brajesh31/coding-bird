# 🎨 Documentation Assets

This directory stores diagrams and visual references. SVGs are authored conceptual diagrams, not application screenshots or proof of a deployed topology.

- `architecture-overview.svg`: product services and package relationships.
- `trust-boundaries.svg`: conceptual untrusted input, application, private data, realtime, and isolated execution boundaries.

Update diagrams when system boundaries change. Do not present them as UI screenshots or verified infrastructure.
