# 📖 Glossary

| Term | Meaning in Coding Bird |
|---|---|
| App Router | Next.js routing and server/client component model |
| CRDT | Conflict-free replicated data type used to merge concurrent edits |
| Ducklet | Collaborative frontend playground/room |
| Driver | Generated self-contained program containing a solution and test harness |
| Hocuspocus | WebSocket server used to synchronize Y.js documents |
| Hidden tests | Problem cases that must not be exposed through browser-facing APIs |
| tRPC | Type-safe API layer used by the application |
| Turborepo | Task orchestration and caching for the monorepo |
| WebContainer | Browser-based Node.js runtime used by the IDE experience |
| Y.js | CRDT framework used for shared document state |
