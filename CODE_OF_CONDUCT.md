# 🌱 Code of Conduct

## Commitment

Coding Bird aims to be a constructive place for people learning, teaching, building, and reviewing software.

## Expected behavior

- Be respectful, patient, and specific in technical disagreement.
- Critique code and ideas, not people.
- Welcome different experience levels and learning paths.
- Respect privacy, consent, and ownership of code and shared workspaces.
- Report security concerns responsibly; do not expose other people's data.
- Keep discussions focused and actionable.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, personal attacks, deliberate disruption, sharing private content without permission, and retaliation for good-faith reporting are not acceptable.

## Enforcement

Report concerns privately to the repository maintainer through GitHub's private contact/reporting options. Maintainers may remove content, restrict participation, or take other action needed to protect the community. This policy applies to repository discussions, issues, pull requests, project spaces, and events explicitly organized under Coding Bird.
